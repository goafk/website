How it works

Built on the protocol Zed already speaks.

Zed talks to its agents over the open Agent Client Protocol (ACP). afk sits quietly in that conversation. Nothing to fork, nothing to patch.

editorZed

Unchanged. You keep using it exactly as before.

ACP
afk relayMirrors every message

Sits between Zed and each agent; can send prompts, answers and settings back.

local
afk hub · your MacThreads & history

Reads Zed's sidebar, keeps history, sends notifications.

network
afk appYour phone

Same projects, same threads, same order as Zed.

No fork of Zed

No patched binary, no extension. Setup adds a few clearly marked lines to Zed's settings, backed up first.

If afk stops, Zed doesn't

The relay passes everything through. With the hub down, Zed and your agents keep working normally.

Claude Agent, Codex, more

Fully live with Claude Agent and Codex today; other ACP agents in Zed through a synced entry.

Private by design

Your Mac is the server. There's no afk cloud.

Stays on your Mac

Threads, history and code never leave your machine for an afk server, because there isn't one.

A key per phone

Pair by scanning a one-time code. Each phone gets its own key; revoke any of them in one command.

Encrypted anywhere

Away from home, afk connects through Tailscale over HTTPS. Nothing is exposed to the open internet.

App lock

Fingerprint or Face ID after the time away you choose.

One honest caveat: push notifications are delivered by Expo and Google (Firebase). A notification contains the project name, the thread title and a short snippet of the agent's message. Details.

Install

One line on the Mac. One scan on the phone.

  1. Run the installer

    It brings its own Node.js if needed, syncs Zed's agents, starts the hub and sets up Tailscale if you have it.

  2. Scan the code

    Open the afk app and scan the QR code the installer prints. Your phone gets its own key.

  3. Step away

    Restart Zed once if setup asks. That's it.

FAQ

Questions, answered.

Is afk free?

Yes. The Mac side and the app are free, and the code is MIT licensed.

Which agents work with it?

Claude Agent and Codex in Zed are fully live: every thread, both ways. Other agents that Zed runs over ACP work through a "(synced)" entry that setup adds to Zed.

Do I need Tailscale?

No. On the same Wi-Fi the phone talks to your Mac directly. Tailscale (free for personal use) lets it reach your Mac from anywhere, encrypted, without opening any ports. Setup configures it for you if it's installed.

Is my code sent anywhere?

No afk server exists: your threads and code stay on your Mac, and the phone reads them from it. The exception is push notifications, which travel through Expo and Google and carry the project name, thread title and a short snippet.

What does it change in Zed?

Setup adds a few lines to Zed's settings.json and keymap.json, between clear afk:begin / afk:end markers, after backing both files up. afk uninstall removes them.

What if my Mac is asleep?

The hub runs on your Mac, so it needs to be awake for live use. Starting a brand-new thread from the phone also needs Zed running, since afk opens it there for you.

Can I use it with two Macs?

Yes. Install afk on each and scan each Mac's code. The switcher at the top shows one Mac at a time and badges the other when it needs you.

iPhone?

The app is built cross-platform; the iPhone version is on its way to the App Store. Android works today.

Windows or Linux?

Not yet. The hub is macOS-only for now.
